# Vaani onboarding image-generation plan

Only three original, text-free background images will be generated. Each is
portrait 9:16, reviewed with a top text zone (0–35%) and a bottom CTA zone
(84–100%) overlaid, then exported as 1440 × 2560 lossless PNG and matching
WebP. A plain `#0C1020` fallback and adjustable scrim make onboarding usable
when art is unavailable or reduced motion is enabled.

| Asset | Screen | Candidates | Review and selection criteria | Safe zones |
|---|---|---:|---|---|
| `01-arrival-voice-space` | Welcome / Get started | 3 compositions: blurred foreground, offset workspace, quiet light pool | No readable object/device; dark upper third, calm warm lower field, cobalt dominant and one coral reflection | top 0–35%; bottom 84–100% |
| `02-keyboard-handoff` | Enable Vaani Keyboard | 3 compositions: left-lit rhythm, diagonal translucent planes, soft stacked forms | Central instructions remain clear; no literal keys/letters; one directional cobalt light, restrained coral edge | top 0–25%; center 32–64%; bottom 84–100% |
| `03-ready-to-speak` | Allow microphone / Try a sentence | 3 compositions: low focal core, side-lit layers, distant diffuse core | Top stays dark; low focus never resembles a microphone/waveform/AI orb; coral remains a tiny signal | top 0–35%; bottom 84–100% |

Generation constraints: no people in focus, devices, phones, app screens, logos,
text, letters, icons, watermarks, green, gradients, robots, brains, soundwave
logos, or copied reference compositions. Candidate review sheets will include a
native-only wireframe overlay; no UI is baked into artwork.
