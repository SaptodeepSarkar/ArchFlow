# Bug audit — 11 September 2026

Scope: source review of the controller, capture, insertion, worker supervision,
core protocol/reconciliation, QML, installer, model setup and Arch packaging.
This is a verified findings list, not a guarantee that every bug has been found.
Live microphone, focus, clipboard and compositor behavior still needs testing.

## Fixed in this working tree

| Finding | Change |
|---|---|
| Overlay displayed the whole provisional phrase, including whole sentences in copy-only mode | Shows the last two recognized words, with the newest marked provisional. The previous provisional word moves left when another word arrives. |
| UI colors were hardcoded | Shared palette follows Caelestia's `scheme.json` through a file watcher; independent fallback palette. |
| Settings searched visual parents for a nonvisual controller scope | Explicit bridge property, connection-time config request, refresh after saved changes. |
| Snapshot condition excluded actual snapshots from normal state handling | Snapshots now use the same state handler as events. |
| IDLE immediately destroyed the overlay despite its outcome timer | Outcome remains visible during the timer. |
| Closing settings could leave its process resident | Closing settings checks the idle shutdown condition. |
| RECORDING notices erased an existing preview | Clear preview only when entering recording. Clear it when recording ends. |
| READY had no recovery controls | Copy and dismiss controls in the overlay. |
| Failed clipboard offers were announced as successful | Broadcast the actual copy result. |
| Pending expiry was broadcast through an unused sender | Use the connected event broadcast channel. |
| Events could fall between snapshot creation and subscription | Subscribe before snapshot creation. |
| A lagged subscriber lost its event stream permanently | Resume after broadcast lag. Lost events are not replayed. |
| IPC line length was checked after unbounded allocation | Bound reads before parsing, including unterminated lines. |
| Starting another daemon unlinked a live daemon socket | Refuse startup when the existing socket accepts a connection. This is not an atomic process lock. |
| Translation setting never reached the worker | Pass `--translate` when enabled. |
| Byte truncation could panic inside Hindi/Bengali characters | Truncate at UTF-8 boundaries in worker and clipboard helpers. |
| Live cleanup attempted READY → CLEANING, which the state machine forbids | Complete cleanup before entering READY. |
| Revised final recognition could be silently treated as already typed | Offer the full revised transcript for review/copy. |
| Late insertion completion could change a newer session | Verify session/state before applying completion. This cannot retract an already dispatched paste. |
| Clean installations without an existing Quickshell directory skipped UI installation | Always install the app-owned configuration. |
| Quickshell name lookup failed when another shell owned the default config; system assets were outside config search paths | Launch by explicit resolved user/system path. |
| Packaged user unit pointed at `~/.local/bin` | System package uses `/usr/bin`; local installer writes its own binary path. |
| Unit documentation pointed to a different project; restart window missing | Correct repository URL and explicit restart interval. |
| PKGBUILD used an example URL, wrong archive root and inactive lifecycle functions | Real repository, `ArchFlow-*` root and separate `.install` hooks. |
| Installer ignored XDG configuration/data locations | Honor XDG variables and pass the daemon socket path to its UI. |
| Settings offered unimplemented history/residency behavior as available | Disable history control and offer Economy only; explain remaining modes. |

## Remaining confirmed issues and limitations

| Priority | Location | Finding / effect |
|---|---|---|
| High | `crates/vaanid/src/worker_sup.rs::silero_trailing` | Production VAD writes audio to a predictable temporary WAV path. Concurrent calls can collide. This contradicts the in-memory privacy requirement. |
| High | `worker_sup.rs::run_once` | Worker writes/waits have no effective timeout or cancellation handle. A hung child can stall an operation; cancel invalidates its result but does not terminate it immediately. |
| High | `daemon.rs::lock_watch`, `inserter.rs` | Lock checking uses `pgrep hyprlock`, misses other lockers/suspend and does not cancel every inference/insertion state. Held modifiers are not verified before paste. |
| High | `daemon.rs::live_loop`, `inserter.rs` | Cancellation/settings changes can race an already-started blocking paste. Focus is checked before clipboard acquisition, leaving another race before dispatch. |
| High | `capture.rs`, `daemon.rs::amplitude_loop` | Spawn success is called microphone readiness. Disconnected capture is not distinguished from an empty channel; a dead capture can remain RECORDING without reaching its sample-count duration cap. |
| High | `daemon.rs` UI launch | UI spawn errors/crashes do not stop capture, so recording may continue without an indicator. |
| Medium | `daemon.rs::stop_flow` | Stop during STARTING attempts a forbidden STARTING → TRANSCRIBING transition. Transition errors are widely ignored. |
| Medium | `daemon.rs` recovery | Error messages promise audio retry, but `recover_pending` only returns pending text. Retained failed audio has no implemented retry/expiry path. |
| Medium | `daemon.rs::live_loop` | Repeated cumulative inference is chunked, not true word streaming. Holding four words back does not prove the earlier words are stable across recognition passes. Focus loss stops previews too. |
| Medium | `clipboard.rs` | Clipboard ownership lifetime/restoration settings are not implemented. `wl-copy` can leave a serving helper; snapshot output allocation is unbounded before truncation. |
| Medium | `inserter.rs::dispatch_key` | Paste uses only the locally verified Lua Hyprland API. Classic Hyprland can fall back to copy-only. Universal Wayland insertion is not supported. |
| Medium | `daemon.rs` | Existing expiry and lock watchers wake periodically at idle; the lock watcher spawns `pgrep`. This violates the specified idle economy policy. |
| Medium | `daemon.rs::ConfigSet`, `MicTest` | A failed config save leaves changed in-memory config. Mic test runs synchronously, uses the default source rather than configured source, and reports silence instead of a capture failure. |
| Medium | `tools/model-setup.py`, `models/manifest.toml` | Downloader skips hashing without explicit `--sha256`, trusts existing files by size, and does not load manifest hashes. Several manifest hashes are placeholders. |
| Medium | `tools/setup-stt.sh` | Existing whisper binary with no upstream checkout can break VAD download/sample verification. Temporary verification filename is fixed; dynamic-library portability of copied binaries needs checking. |
| Medium | `packaging/PKGBUILD` | Published archive recipe still needs a pinned release checksum. The new local-package script calculates its own checksum. These working-tree changes are not in the existing GitHub tag. |
| Medium | `paths.rs`, CLI | No-runtime-dir fallback uses an assumed UID; standalone CLI/UI fallback paths are inconsistent. Normal graphical sessions supply XDG_RUNTIME_DIR. |
| Low | Settings / config | App overrides have no editor; model download is still a CLI setup step; profile/history implementation remains incomplete. |
| Low | Documentation | Older ADR/spec paragraphs conflict with newer STT/VAD implementation. README descriptions should not be treated as hardware validation. |

The existing protocol carries transcript strings in JSON over local IPC. This
also conflicts with the stricter AGENTS rule against transcripts in JSON; a
separate text transport would require a protocol migration.

## Validation

- `cargo build --workspace` passes; `cargo test --workspace`: 38 tests pass.
- Settings and theme load in an isolated offscreen Quickshell smoke test.
- Local package source staging and generated SHA-256 checksum verified; the
  full `makepkg` build and privileged package installation were not run.
- `qmllint ui/shell.qml ui/SettingsView.qml ui/Theme.qml` passes.
- Shell syntax and `git diff --check` pass.
- Added coverage for two-word advancement, corrections and mixed scripts.
- The installed settings window loaded successfully through Quickshell 0.3.1
  on the laptop's active Wayland session. A live launch caught and fixed an
  unsupported `FloatingWindow.palette` assignment that static lint missed.
- The recording overlay and real speech preview still require a deliberate
  spoken-input check; this audit did not fabricate a microphone result.
- The user-local installation and service restart were verified on the laptop;
  this report does not claim a broad speech-accuracy benchmark.

## v0.5.1 live-hardware follow-up

- The default EasyEffects virtual source produced a transient peak but almost
  no average signal. The laptop installation now selects the stable built-in
  Realtek source without changing the global PipeWire default.
- The application speech gate accepts quieter microphone input (`0.005` RMS),
  with Whisper VAD retained as a second stage at a `0.35` threshold.
- A separate static whisper.cpp CUDA CLI was built for compute capability 8.6.
  It detected CUDA0, loaded the base model into the RTX 3050, and transcribed
  the upstream 11-second JFK sample correctly in about 1.06 seconds.
- The overlay now contains only the waveform and transcript/status text.
- The physical microphone showed signal (`0.063` peak) while idle, but no
  spoken acceptance sample was recorded during this automated check. Actual
  voice recognition still needs one deliberate sentence from the user.

## v0.5.2 insertion follow-up

- The exact clipboard plus Hyprland Lua `send_shortcut` path was verified in
  an isolated Quickshell text field, without targeting the user's application.
- Insertion now verifies that the clipboard offer is readable, then rechecks
  the original window immediately before dispatch. Non-content outcome details
  are written to the service journal for future diagnosis.
- Clipboard fallback now completes the state machine at `IDLE`. Both successful
  paste dispatch and clipboard fallback trigger a 320 ms downward overlay exit.
- The unavoidable focus race between the last check and key delivery remains;
  Hyprland does not provide an atomic paste-into-original-cursor operation.
