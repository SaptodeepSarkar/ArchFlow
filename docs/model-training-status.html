Vaani model training status

Evidence snapshot: 14 September 2026. This page distinguishes completed training runs, explicit local test wiring, and promoted production models.

STT

V5 enabled for local testing

The V5 Whisper-derived CT2 candidate is wired to the local Super+H path; V2/Cozy remains the benchmark control.

Control WER: 5.49244% on the full corpus; V5 is not promoted.

LLM / formatter

Training runs completed; no new model promoted

V5 SFT/DPO/GRPO and V6 tagger experiments were evaluated and rejected as replacements.

The production-safe behavior currently comes from the existing formatter control plus deterministic guards.

Mobile speech benchmark

Partially measured

Android launch and memory smoke test passed. Speech WER, CPU streaming RTF, battery, and speech-to-insertion latency are not measured.

Direct answer

Current test wiring: local configuration selects STT alias v5 and the V5 SmolLM2 formatter base/adapter. Restarted Vaani successfully; this is an opt-in experiment, not a quality or safety promotion.

QuestionAnswer
Is the STT training done?Yes, for the current V2/Cozy control. The Whisper-derived fine-tuned path exists, is converted to CT2, and has been benchmarked. Later V5 alternatives did not beat it and were not promoted.
Is the LLM training done?Experiments are done, but a new production formatter is not. SFT/DPO/GRPO runs and V6 source-grounded tagger runs completed; none passed the promotion gate. The V6 learned tagger is research-only.
Is the final system near 1–2% WER?No. The current measured control is about 5.49% normalized WER on the reported full-corpus control. The 1–2% goal has not been achieved or verified.
Can we claim mobile speech speed?No. Android launch/memory was measured, but no Android audio utterance was run, so speech WER and speech-to-insertion latency remain unknown.

Current LLM verdict: the model is not yet a dependable autonomous cleanup writer. The safe system limits it to source-grounded decisions and lets deterministic code handle emoji cues, lists, replacements, snippets, and safety boundaries.
