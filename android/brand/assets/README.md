# Vaani brand asset set

These assets were generated as original Vaani artwork using the image-generation skill. The website hero was used only as a mood reference for warm light, natural movement, and quiet depth. It was not used as an edit target, and no Wispr Flow asset, trademark, layout, or text was copied.

## Assets

- `vaani-android-banner.png`: warm editorial banner for onboarding/documentation; no text or UI.
- `vaani-flow-ribbon.png`: transparent paper-ribbon motif for the onboarding flow; no text, logo, sparkle, or glow.

The Android app uses optimized WebP derivatives in `app/src/main/res/drawable-nodpi/` to avoid shipping the large source PNGs in the APK. Keep the source PNGs here for documentation/marketing use and preserve their provenance with future releases.

The companion banner intentionally carries the same emotional temperature as `website/assets/vaani-hero.png` while changing the setting and composition. It is original artwork, not an edit or a clone.
