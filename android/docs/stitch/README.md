# Stitch reference package

These files were retrieved from Stitch project `5328162692191810137` on 2026-09-15 using the supplied screen IDs. Each mobile screen has its source HTML and screenshot; the specification is preserved as Markdown.

The implementation follows the `Editorial Tactile` system: `#f8faf5` paper, pine green `#2d5a3d` progression, warm amber only for the live cursor/focus, Epilogue-like display hierarchy, Hanken-like body copy, segmented progress rules, and hard tactile surfaces.

The Android onboarding intentionally does not use a photographic splash. Page one uses the green V mark as a full-surface visual anchor and a tactile audio/keycap motif, so the mark remains legible and does not sit on a white image rectangle. The source banner remains available under `android/brand/assets/` for approved marketing placements, not as an onboarding background.
